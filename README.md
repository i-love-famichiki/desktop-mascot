# Desktop Mascot（デスクトップマスコット）

デスクトップに住む、枝豆の豆1粒のマスコットです。クリックして話しかけると、
Gemini が吹き出しで返事をします。Windows 用・Electron 製。

- 背景が透明なウィンドウで、いつも一番手前にいます
- 豆の周りの透明な部分はクリックが素通りするので、後ろのアプリを普通に操作できます
- ときどき豆がコロンと転がります

> [!NOTE]
> このアプリは、AI の [Claude](https://claude.com/claude-code)（Claude Code）と一緒に作りました。
> 使ったことで起きた問題や損害について、作者は責任を負いません。ご自分の判断でお使いください。

## できること

**会話**
- 話しかけると 1 秒前後で返事（Google 検索を使ったときは 2〜3 秒）
- 今日の直近 20 往復を覚えていて、話の続きができる
- 昨日から 6 日前までの会話は、要約して返事に使う
- それより古い会話は月ごとの保管庫に残り、「去年の夏に話したこと」のように言葉で探せる
- 昔の会話を残したくないときは、設定で「昔の会話を覚える」を切れる（今日の会話は覚えている）

**口調**
- 毒舌・硬さ・素直さ・優しさ・かわいさ・感情の起伏の 6 つのつまみで口調を決め、5 つまで保存できる
- 毒舌は、相手の言葉を毎回 AI で判定して、刺す理由があるときだけ出す（判定できなかった回は出さない）

**タイマーとリマインダー**
- 「10 分後に教えて」「明日の 9 時に会議」のように話しかけて登録できる
- 時間になると音を鳴らして声をかける

**Google カレンダー**
- 「今日の予定は？」「金曜の 15 時に歯医者を入れて」と話しかけて、予定を読む・足す
- 予定の変更と削除もできる（消す前に、どの予定か必ず確かめる）
- 予定の 10 分前に知らせ、その日はじめて起動したときは今日の予定をまとめて言う

**画像を小さくする**
- 画像を豆にドロップして「500KB にして」「メール添付用にして」と話しかけると、
  小さくしてデスクトップに置く（外部のライブラリは使わず Electron の機能だけで行う）

**見た目と音**
- 豆の絵は 4 種類から選べる（はじめは なめらか。ほかに 8 ビット風の あらい・ふつう・こまかい）
- お知らせの音と、返事が出たときの音を選べる。内蔵の 5 種類のほか、
  自分の持っている音のファイル（mp3・wav・ogg・m4a・flac）も使える

**AI とキー**
- 天気やニュースは Google 検索で調べて、出典のサイト名も出す（設定で切れる）
- 返事を作るモデルを、軽い（flash-lite）・かしこい（flash）から選べる
- API キーは、設定画面に貼るか、環境変数から読むかを選べる
- 今月使った回数とトークンの数を設定画面で見られる

**その他**
- 会話の履歴を Google ドライブなどの共有フォルダに置けば、複数の PC で同じ会話を続けられる
- Windows 起動時の自動起動
- 設定ウィンドウ（右クリックメニューの「設定を開く…」）で、上のことをまとめて変えられる

## 使うために必要なもの

- Windows
- [Node.js](https://nodejs.org/) 20 以上（開発版を動かす場合）
- Gemini API キー（[Google AI Studio](https://aistudio.google.com/) で取得）。起動したら、設定の「KEY」タブに貼る
- （カレンダー連携を使う場合のみ）Google Cloud で作った「デスクトップ アプリ」用の
  クライアント ID の JSON。設定ウィンドウから 1 回だけ選べば、あとはログインするだけです。
  **このリポジトリに作者の分は入っていません。使う方がご自分で取得してください**

### 無料枠のキーで使うとき

無料枠のキーでも話せますが、次の点に気をつけてください（2026-09 に確認）。

- **返事がとても遅い。** 検索なしでも 20〜30 秒かかりました（有料枠は 1 秒前後）。
  混んでいると、60 秒待っても返事が来ないことがあります
- **Google 検索が使えない。** 検索つきの呼び出しは `429 RESOURCE_EXHAUSTED` で断られます。
  断られたときは、検索なしで自動でやり直します。設定の「KEY」タブで「Google 検索を使う」を
  切っておけば、はじめから検索なしで呼びます
- **口調が反映されにくい。** 毒舌や気持ちの出し方を決める判定の呼び出しも、混んでいて
  断られることが多く、判定できなかった回は毒舌なしで返します

天気やニュースも調べさせたい場合は、Google Cloud で支払い設定をしてください（有料枠）。
検索を使った返事には、通常の返事とは別に検索の料金がかかります。

無料枠では、送った内容が Google のサービス改善に使われることがあります。
有料枠では使われません。

### 送る内容と、残す内容について

- 話しかけた内容は、返事を作るために Google（Gemini API）に送られます
- 会話の履歴と保管庫は、この PC の中（`%APPDATA%Desktop Mascot`）に保存します
- 共有フォルダ（Google ドライブなど）に置いた会話は、**暗号化していません。** ドライブの
  プレビューなどで中身が見えます。気になる場合は共有しないでください
- 設定画面に貼った API キーと、カレンダーのログイン情報は、Windows の仕組みで暗号化して保存します

## 動かし方

```sh
git clone https://github.com/i-love-famichiki/desktop-mascot.git
cd desktop-mascot
npm install
```

起動します。

```sh
npm start
```

### exe を作る

```sh
npm run dist
```

`dist/DesktopMascot-Setup.exe` ができます。

## 操作

| したいこと | 方法 |
| --- | --- |
| 話しかける | 豆をクリック |
| 動かす | 豆をドラッグ |
| メニューを出す | 豆を右クリック、またはタスクトレイのアイコン |
| 設定を変える | 右クリックメニューの「設定を開く…」 |
| 画像を小さくする | 画像を豆にドロップして、大きさを話しかける |
| 吹き出しを閉じる | 右上の「×」 |
| 吹き出しを縮める | 右上の「－」 |

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `main.js` | Electron のメインプロセス。ウィンドウ、Gemini API 呼び出し、システムプロンプト、タスクトレイ |
| `preload.js` / `renderer.js` / `index.html` / `style.css` | 画面側。マスコットの SVG（4 種類）と吹き出し |
| `settings-window.html` / `settings-window.js` / `settings-preload.js` | 設定ウィンドウ |
| `calendar.js` | Google カレンダーの予定の読み書きと、お知らせ・朝のまとめの文 |
| `google-auth.js` | Google のログイン。長く使える鍵は Windows の safeStorage で暗号化して保存 |
| `image-compress.js` | 画像を小さくする処理 |
| `sounds.js` / `sound-player.js` | 鳴らす音の決め方と、実際に鳴らす処理 |
| `history-store.js` | 会話履歴の保存と、古い会話の要約 |
| `archive-store.js` | 会話の保管庫と、昔の会話を言葉で探す処理 |
| `reminder-store.js` | タイマーとリマインダー |
| `settings.js` | 設定の読み書き |
| `sse.js` | Gemini からの返事を少しずつ受け取る処理 |
| `tone.js` | 口調の 6 つのつまみと、プリセット |
| `appraisal.js` | 相手の言葉から気持ちを判定して、毒舌の強さを決める |
| `chat-tools.js` | 会話のたびに、使いそうな道具（タイマー・カレンダーなど）だけを選んで渡す |
| `token-log.js` | 使ったトークンを日ごと・モデルごとに記録し、月の料金の目安を出す |
| `api-key.js` | API キー。環境変数から読むか、設定画面に貼ったキーを暗号化して保存する |

会話の履歴や設定は `data/` に保存され、Git には含めません。

## 作りについて

- AI は Gemini API（`gemini-3.5-flash-lite`、設定で `gemini-3.5-flash` にも変えられる）。外部 SDK は使わず、Electron の
  `net.fetch` で `generateContent` を直接呼んでいます
- `tools: [{ google_search: {} }]` を付け、検索するかどうかはモデルに任せています。
  検索つきで `429` が返ったとき（無料枠のキー）は、検索を外してやり直します
- マスコットの絵は自作の SVG です。8 ビット風の 3 種類は、四角を並べて描いています
- カレンダー連携は外部のパッケージを使わず、Google の「パソコンのアプリ向けのログイン方法」
  を自前で実装しています。ログインを受け取るサーバーは `127.0.0.1` だけで待ち受け、
  ポートはそのつど空いているものを使います
- デスクトップ アプリの `client_secret` は、仕組みの上でどのみち秘密にできない値です
  （[RFC 8252](https://datatracker.ietf.org/doc/html/rfc8252) でいう public client）。
  ログイン途中の認可コードの横取りは PKCE で防いでいます（なりすましそのものは防げないため、
  同意画面のアプリ名をご確認ください）。そのうえで、クライアント ID と長く使える鍵は
  どちらも Windows の safeStorage（DPAPI）で暗号化して `data/` に置いており、
  同じ Windows アカウントでしか復号できません
- `.npmrc` で、npm のサプライチェーン攻撃への備え（インストール時のスクリプト実行を止める、
  公開から 7 日たっていないバージョンを入れない、など）をしています

使い方の詳細は `マニュアル.html` にあります。
