設定

自動起動

Windows にサインインしたとき、マスコットを自動で立ち上げます。

開発中（npm start）なので、Windows への自動起動の登録は変わりません。設定だけ保存します。

豆の見た目

デスクトップに出ている豆の絵です。大きさは変わりません。

音

お知らせ（タイマー・リマインダー・カレンダー）と、返事が出たときに鳴らす音です。自分の持っている音のファイルも使えます。

昔の会話を覚える

昨日より前の会話を、要約や保管庫に残して、返事や「前に話したっけ？」に使います。

切っても、今日の会話（直近 20 往復）は覚えていて、話の続きができます。切った後の会話は、日付が変わると残さずに捨てます。 切る前にためた昔の会話は消さずに残しているので、また入れればもう一度思い出せます。

ほかの PC と会話を共有

Google ドライブなど、ほかの PC と同期しているフォルダに会話を保存して、同じ会話を続けられます。

カレンダー連携

Google カレンダーの予定を教えたり、会話で予定を入れたりします。予定の10分前に知らせ、その日はじめて起動したときは今日の予定を言います。

Google アカウント
予定を読み直す間隔

ほかの所（スマホなど）で予定を変えたとき、豆が気づくまでの時間です。短いほど早く気づきます。

クライアント ID のファイル（最初に1回だけ）
Google Cloud で「デスクトップ アプリ」用に作った JSON です。作り方は、マニュアルの「カレンダー連携をつなぐ」にあります。

口調のプリセット

まめの話し方を、6つのつまみで決めます。5つまで保存でき、ここで選んだものが次の返事から使われます。

このプリセットの名前
つまみ
このプリセットは、今までのまめの口調そのままです。つまみは使いません（動かしたいときは、ほかのプリセットを選んでください）。

どんな数値でもしないこと

つまみをどこまで上げても、次のことはしません。

    API キー

    Gemini を使うためのキーです。下の2つのうち、どちらか1つを選びます。

    環境変数は、setx で入れたものの名前を書きます（GEMINI が付く名前は候補に出ます）。新しく setx で入れたものは、豆を起動し直すと読めます。 貼ったキーは、この PC の Windows の仕組みで暗号化して保存します。ほかの PC では使えないので、PC ごとに貼ってください。
    無料枠のキーの制限（2026-09 時点）: 返事に 20〜30 秒かかり、混んでいると時間切れになることがあります。 Google 検索は使えません（天気やニュースは調べられません）。口調も反映されにくくなります（相手の言葉を見て毒舌や気持ちの出し方を決める判定が、混んでいて失敗しやすいため）。 快適に使うには、Google Cloud で支払い設定をした有料枠のキーがおすすめです。

    AI モデル

    返事を作る AI です。かしこいほうは口調の指示によく従いますが、そのぶん料金が高くなります。

    かしこいほう（flash）でも、内部で考えるぶんの課金は切ってあります。切り替えは、次に話しかけるときから効きます。

    Google 検索

    天気やニュースなど、新しい情報が要るときに Google で調べてから答えます。

    API キーが無料枠のときは、切ってください。検索つきの返事は無料枠では断られるため、入れたままだと雑談もできません。切ると天気やニュースには答えられなくなります。

    使った量

    トークンは、AI が読み書きした文字の量の単位です。「返事」には、返事の前に AI が考えた分も入ります。 無料枠のキーならお金はかかりません。有料枠の金額は Google Cloud の請求の画面で確かめてください。
