枝豆マスコットの手引き

ほかの PC にインストールして、話しかけられるようにするまでの手順です。

用意するもの

  • インストーラー　DesktopMascot-Setup.exe（約 110MB）
  • Gemini の API キー　今の PC で使っているのと同じキーで使えます
  • 64 ビット版の Windows　10 か 11
  • クライアント ID のファイル　カレンダーを使うときだけ。client_secret_….json（下の手順）

インストーラーは、元の PC の C:\Users\user\Desktop-Mascot\dist\ に入っています。

インストールの手順

  1. インストーラーを持っていく

    USB メモリや Google ドライブを使って、インストーラーを新しい PC にコピーします。置く場所はデスクトップなど、どこでもかまいません。

  2. ダブルクリックしてインストールする

    確認の画面は出ずにインストールが終わり、マスコットが画面の右下に出てきます。

    青い「Windows によって PC が保護されました」が出たとき
    「詳細情報」を押すと出てくる「実行」を押してください。自作のアプリには発行元の証明が付いていないため、この画面が出ます。
    アバストなどのセキュリティソフトが止めたとき
    危ないファイルではありません。下の「セキュリティソフトの例外に入れる」のとおり例外に入れてから、もう一度ダブルクリックしてください。

  3. API キーを登録する

    豆を右クリックして「設定を開く…」→「KEY」のタブを開きます。「キーをここに貼る」を選んで、自分の API キーを貼り、「確かめて保存」を押します。「保存しました」と出れば終わりです。

    • キーは、この PC の Windows の仕組みで暗号化して保存されます。ほかの PC では、PC ごとに貼ってください
    環境変数で登録する場合（前のやり方）

    スタートボタンを押して「環境変数」と入力し、「環境変数を編集」を開きます。上の「ユーザー環境変数」の「新規」を押して、次のように入力します。

    変数名
    GEMINI_API_KEY
    変数値
    自分の API キー
    • 変数名は 1 文字でも違うと読まれません。コピーして貼り付けてください
    • 下の「システム環境変数」ではなく、上の「ユーザー環境変数」に入れます
    • 最後は開いた画面をすべて OK で閉じます
    PowerShell で登録する場合

    次の 1 行を実行します。ここにキー の部分は自分のキーに置き換えてください。

    setx GEMINI_API_KEY "ここにキー"

    環境変数は、マスコットを起動したときに読みます。登録したら、一度終了してから起動し直してください（豆を右クリック →「終了」、スタートメニューの「Desktop Mascot」で起動）。そのあと「KEY」タブで「環境変数から読む」を選び、変数名を書いて「この名前にする」を押します（GEMINI_API_KEY なら、はじめから選ばれています）。

  4. 話しかけて確かめる

    豆をクリックすると入力欄が出ます。「今日の天気は？」などと話しかけて、吹き出しで返事が来れば準備完了です。

使い方

やりたいこと操作
話しかける豆をクリックして、入力欄に書く
タイマー・リマインダー「3分たったら教えて」「明日の9時に歯医者って教えて」と話しかける。時間が来たら音が鳴って、豆がはねて知らせる。「今の予定は？」「歯医者のは取り消して」も話しかけて行う
予定を聞く・入れる・直す・消す「今日の予定は？」「金曜の15時に歯医者を入れて」「歯医者を16時に直して」「歯医者の予定を消して」と話しかける。「1001歓迎会1900」のような数字だけのメモ書きでも入る（10月1日 19:00 と読む）。「930会議」のように日付とも時刻とも読めるときは、豆が聞き返す。消す前にも、どの予定か確かめてくる。予定の10分前に知らせ、その日はじめて起動したときは今日の予定をまとめて言う。先にカレンダー連携をつなぐ
画像を小さくする画像を豆にドロップして、「500KBにして」「半分にして」「メール添付用にして」と話しかける。小さくしたものはデスクトップに置く
昔の話を思い出してもらう「前にキャンプの話ってしたっけ？」「一年前に仕事のことで相談しなかった？」と話しかける
置き場所を変える豆をドラッグする
隠す・また出す画面右下のトレイにある豆のアイコンをクリックする
会話の履歴を見る・リセット豆を右クリックして、メニューから選ぶ
豆の見た目を変える右クリックメニューの「設定を開く…」→「豆の見た目」。なめらかな豆と、8ビット風の3種類から選べる
音を変える・止める「設定を開く…」→「音」。お知らせの音と、返事が出たときの音を別々に選べる。自分の持っている音のファイル（mp3 など）も使える。うるさいときは「鳴らさない」に
口調を変える「設定を開く…」→「口調」のタブ。「いつもの まめ」のほかに、毒舌・硬さ・素直さ・優しさ・かわいさ・感情の起伏の6つのつまみで決めた口調を4つまで保存できる。選んだ口調は次の返事から変わる。口調は設定の画面でしか変えられない（豆に「元に戻って」と話しかけても変わらない）
返事を作る AI を変える「設定を開く…」→「KEY」のタブ →「AI モデル」。「かしこい（flash）」は口調の指示によく従うが、料金が高くなる
API キーを変える「設定を開く…」→「KEY」のタブ。「環境変数から読む」か「キーをここに貼る」の、どちらか1つを選ぶ
Google 検索を使わない「設定を開く…」→「KEY」のタブ →「Google 検索を使う」のチェックを外す。天気やニュースには答えられなくなる
使った量を見る「設定を開く…」→「KEY」のタブ →「使った量」。今月の回数と、料金の目安が出る
昔の会話を残さない「設定を開く…」→「昔の会話を覚える」のチェックを外す。今日の会話は覚えているが、日付が変わると残さない（前にためた分は消さずに残る）
Windows と一緒に起動しない「設定を開く…」→「自動起動」のチェックを外す
ほかの PC と会話を共有する右クリックメニューの「ほかの PC と会話を共有」（下の手順）
バージョンを確かめる右クリックメニューの「このアプリについて」
終了する右クリックメニューの「終了」

うまくいかないとき

APIキーが見つからないみたい。設定の「KEY」タブで、キーを選ぶか入れてね。

キーがまだ読まれていません。「KEY」タブで、キーを貼って保存してください。環境変数で入れた場合は、変数名が合っているか確かめてから、マスコットを起動し直してください。

APIキーが正しくないみたい。設定の「KEY」タブで、キーを確かめてね。

キーの値が違います。前後に空白が入っていないか、途中で切れていないか確かめてください。

喋りすぎたか、検索の利用上限に達したかもしれない。

短い時間に使いすぎました。少し待ってから話しかけてください。

考えこみすぎちゃったみたい。もう一回話しかけて。

60 秒待っても返事がありませんでした。無料枠のキーは返事に 20〜30 秒かかることがあり、混んでいるとこうなります。もう一度話しかけてください。

ネットにつながらないみたい。

インターネットにつながっているか確かめてください。

Google のアカウントのログインが切れてるよ。

「設定を開く…」→「カレンダー連携」の「Google でログイン」を押して、ログインし直してください。ほかの PC の豆で「ログアウト」を押したときも、こうなります。

設定が「予定の通知だけ」になってるから、会話では予定を見たり入れたり消したりできないよ。

「設定を開く…」→「カレンダー連携」で「会話でも予定を読み書きする」を選んでください。「ログアウト」してからログインし直したときは、「予定の通知だけ」に戻っています。

予定を頼んだのに、カレンダーに入っていない

豆は入れた予定の日付と時刻を言うので、まずそこを確かめてください。思っていたのと違う日に入っていることがあります。返事に日付が無いときは入っていないので、「10月1日の19時に歓迎会を入れて」のように、もう一度はっきり頼んでください。

口調を切り替えたのに変わらない・口調が弱い

設定の画面で、使いたい口調が選ばれているか確かめてください。選んである口調は、次の返事から変わります。

毒舌は、いつも出るわけではありません。豆は話しかけられるたびに、先に AI で「相手の言葉に、刺す理由があるか」を判定し、理由があるときだけ毒舌を出します（あいさつや普通の質問には刺しません）。この判定ができなかった回は、毒舌なしで返します。

無料枠のキーでは、この判定が「混み合っています」で失敗しやすく、毒舌や気持ちの出し方が反映されにくくなります。また、軽い AI（flash-lite）は口調の指示に従いきれないことがあります。口調をはっきり出したいときは、有料枠のキーと「かしこい（flash）」を使ってください。

豆が出てこない

隠れているだけかもしれません。トレイの豆アイコンをクリックしてください。アイコンが見えないときは、トレイの「^」を押すと出てきます。

ほかの PC と会話を共有する

Google ドライブのフォルダに会話を保存して、どの PC のマスコットとも同じ会話を続けられるようにします。ほかの PC で話した内容は、5 秒ほどで反映されます。

  • Google ドライブのアプリ　共有するすべての PC に入れて、同じ Google アカウントでログインしておく

  1. 共有するフォルダを選ぶ

    豆を右クリックして「ほかの PC と会話を共有」→「共有するフォルダを選ぶ…」を押します。

  2. マイドライブを選ぶ

    「マイドライブ」を選んで「このフォルダで共有」を押します。中に Desktop Mascot フォルダが作られ、会話はそこに保存されます。

    「会話の共有を始めました」と出れば完了です。

  3. ほかの PC でも同じフォルダを選ぶ

    ほかの PC でも手順 1〜2 を行い、同じ「マイドライブ」を選びます。その PC にあった会話も混ぜてまとめられるので、消えることはありません。

  • 2 台でほぼ同時に話しても、どちらの会話も残ります
  • どれか 1 台で「会話をリセット」すると、すべての PC で消えます
  • 共有をやめるときは「共有をやめる」を押します。それまでの会話は、その PC にも残ります
  • 会話の内容は Google ドライブに保存されます。Google アカウントを人と共用している場合は使わないでください

カレンダー連携をつなぐ

Google カレンダーの予定を、豆に聞いたり入れてもらったりできるようにします。PC ごとに 1 回行います。

  • クライアント ID のファイル　Google Cloud で「デスクトップ アプリ」用に作って、ダウンロードした client_secret_….json。元の PC で使ったものを USB メモリなどで持っていけば、同じものが使えます（作り方は下）
クライアント ID のファイルの作り方（はじめての 1 回だけ。15〜30 分ほど）

Google Cloud のサイトで作ります。画面の名前は、Google の変更で少し違うことがあります。

  1. プロジェクトを作る　Google Cloud コンソールに、カレンダーを使う Google アカウントでログインします。上のプロジェクト名の所を押して「新しいプロジェクト」→ 名前（例: desktop-mascot）を入れて「作成」。できたら、そのプロジェクトを選びます
  2. カレンダーを使えるようにする　左のメニューの「API とサービス」→「ライブラリ」で「Google Calendar API」を探して開き、「有効にする」を押します
  3. 同意画面を作る　「API とサービス」→「OAuth 同意画面」（「Google Auth Platform」と出ることもあります）→「開始」。アプリ名（例: まめ）とサポート用のメールを入れ、対象は「外部」、連絡先のメールを入れて作成します
  4. 自分をテストユーザーにする　同じ画面の「対象」→「テストユーザー」→「ユーザーを追加」で、自分の Gmail アドレスを入れて保存します。ここに入れた人だけがログインできます
  5. クライアント ID を作る　「クライアント」（または「認証情報」→「認証情報を作成」→「OAuth クライアント ID」）で、種類を「デスクトップ アプリ」にして、名前を入れて作成します
  6. JSON をダウンロードする　できたクライアントの「JSON をダウンロード」を押して保存します。これが client_secret_….json です。人に渡さないでください
ログインが 7 日で切れるとき
Google の決まりで、同意画面が「テスト中」のままだと、ログインが 7 日ほどで切れることがあります。切れたら、設定の画面から「Google でログイン」をやり直してください。

  1. クライアント ID のファイルを選ぶ

    豆を右クリックして「設定を開く…」→「カレンダー連携」の「クライアント ID のファイル」で「ファイルを選ぶ…」を押し、JSON のファイルを選びます。

  2. Google でログインする

    「Google でログイン」を押すとブラウザが開きます。アカウントを選び、カレンダーの項目にチェックを入れて「許可」を押します。「ログインできました」と出たら、ブラウザは閉じてかまいません。

    「このアプリは Google で確認されていません」が出たとき
    自分で作ったアプリなので出ます。「詳細」→「（アプリ名）に移動」を押して進んでください。

  3. 「会話でも予定を読み書きする」を選ぶ

    はじめてログインしたときは「予定の通知だけ受け取る」になっています。豆に予定を入れたり消したりしてもらうには、「会話でも予定を読み書きする」に変えます。

    • 予定の通知だけ受け取る … 10分前のお知らせと、朝のまとめだけ
    • 会話でも予定を読み書きする … 上に加えて、話しかけて予定を聞く・入れる・直す・消す。そのぶん 1 回の返事の料金が少し増える
  • 使える状態にないときに予定を頼むと、豆が「ログインが切れてる」「通知だけの設定になってる」など、理由を言います
  • 「ログアウト」を押すと、同じアカウントでログインしているほかの PC の豆もログインし直しになります

セキュリティソフトの例外に入れる

このアプリには、お店で売っているアプリのような発行元の証明（署名）が付いていません。そのため、アバストなどが「知らないアプリ」として警告することがあります。次の 2 つのファイルを例外に入れると、警告が出なくなります。

フォルダではなく、ファイルを指定します
フォルダを指定すると、アバストに「範囲が広すぎる」と言われて入れられません。

例外に入れるファイル

アプリ本体（更新しても名前は変わらないので、入れるのは 1 回だけ）

%LOCALAPPDATA%\Programs\desktop-mascot\Desktop Mascot.exe

インストーラー（USB メモリからコピーしたもの。新しい版も同じ名前なので、入れるのは 1 回だけ）

%USERPROFILE%\Desktop\DesktopMascot_持ち出し用\DesktopMascot-Setup.exe

デスクトップ以外に置いたときは、その場所に読み替えてください。

アバストが %LOCALAPPDATA% のような書き方を受け付けないとき
エクスプローラーのアドレス欄に %LOCALAPPDATA%\Programs\desktop-mascot を貼り付けて Enter を押します。開いたら「Desktop Mascot.exe」を Shift キーを押しながら右クリックし、「パスのコピー」を選びます。コピーされたパスを、前後の " を消してから使います。

アバストでの入れ方

  1. アバストを開き、右上の「メニュー」→「設定」を押す
  2. 「一般」→「例外」を開き、「例外を追加」を押す
  3. 上のファイルのパスを貼り付けて「例外を追加」を押す
  4. もう 1 つのファイルも同じように入れる

アバストのバージョンによって、メニューの名前や場所が少し違うことがあります。

元の PC（開発に使っている PC）の場合

インストーラーは開発用のフォルダで作るので、こちらを例外に入れます。

C:\Users\user\Desktop-Mascot\dist\DesktopMascot-Setup.exe
C:\Users\user\AppData\Local\Programs\desktop-mascot\Desktop Mascot.exe

知っておくこと

  • 料金はキーの持ち主にかかります。同じキーを使うと、どの PC で使った分も合算されます。
  • 無料枠のキーでも話せますが、遅いです。返事に 20〜30 秒かかることがあり、Google 検索は使えません（天気やニュースは調べられません）。口調も反映されにくくなります（毒舌や気持ちの出し方を決める判定が失敗しやすいため）。
  • 会話の履歴は、共有しなければ PC ごとに別々です。保存場所は %APPDATA%\Desktop Mascot です。共有中は マイドライブ\Desktop Mascot に保存されます。
  • リマインダーは PC ごとです。会話を共有していても、登録した PC のマスコットだけが知らせます。PC を切っている間に時間が過ぎたものは、次に起動したときに知らせます。タイマーはマスコットを終了すると消えます。
  • 話した中身は「保管庫」にずっと残ります。「会話をリセット」しても保管庫は消えないので、あとから探せます。保管庫は会話の履歴と同じフォルダの archive です（共有中は Google ドライブの中）。
  • アンインストールするときは、Windows の「設定」→「アプリ」→「インストールされているアプリ」で「Desktop Mascot」を選びます。
